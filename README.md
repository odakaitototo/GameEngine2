# GameEngine2

「レベルデザイン特化」を目指したDirectX11ベースの3Dゲームエンジンです。

## 📌 コンセプト
箱庭型のパズルゲーム等のステージ量産を想定し、「プログラマー以外のプランナーでも直感的にステージを構築できるエディタ環境」を目標に制作しています。ハードコードによる配置を廃止し、UI上での操作とファイルによるデータ管理を統合しました。

## ✨ 主な機能と技術的特徴

* **ImGuiによるエディタUIと3Dシーンのシームレスな統合**
  * DirectXの Render to Texture (オフスクリーンレンダリング) を活用し、ImGuiのウィジェット内に3Dシーンを独立して描画。UI操作と3D空間の入力イベントを完全に分離・座標変換することで、競合のない快適なエディタ操作を実現しました。
* **マウスピッキングによる直感的なオブジェクト選択**
  * 2Dモニター座標から3D空間へのRay（光線）キャストを実装。オブジェクトのワールド逆行列を用いてローカル空間へと変換し、AABB（単純な直方体）で交差判定を行うことで、処理負荷を抑えつつ精度の高いピッキングを行っています。
* **JSONベースの柔軟なセーブ/ロード ＆ プレハブシステム**
  * `nlohmann::json` を採用し、シーン全体やオブジェクト単位（プレハブ）での保存・復元が可能。コンポーネント指向を意識した階層構造でのデータ管理を行い、後からの仕様追加でも過去のデータが壊れない「後方互換性」を確保しています。

## 🛠 開発環境・使用技術
* **言語:** C++
* **グラフィックスAPI:** DirectX 11 / HLSL
* **主要ライブラリ:** ImGui (エディタUI), nlohmann::json (データシリアライズ)
* **その他:** Win32 API

## 🎮 操作説明

### エディタ・カメラ操作
| 操作 | アクション |
|---|---|
| `右クリック` + `W` `A` `S` `D` `Q` `E` | カメラの移動（前後左右・上下） |
| `左クリック` | オブジェクトの選択（マウスピッキング） |

### オブジェクト操作（選択時）
ステージ制作を正確に行えるよう、一定値ごとのスナップ移動（グリッド移動）を採用しています。
| 操作 | アクション |
|---|---|
| `I` / `K` | Z軸方向の移動（奥 / 手前） |
| `J` / `L` | X軸方向の移動（左 / 右） |
| `U` / `O` | Y軸方向の移動（下 / 上） |
